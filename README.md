# Laboratorio · Control de gestión

Dashboard ejecutivo interactivo para análisis integrado de servicios, facturación, cuenta corriente y agenda. Esta edición alojada en Pages es una **demostración pública con datos completamente ficticios**.

## Probar

[Abrir dashboard de demostración](https://augustogrecco.github.io/Laboratorio/)

Incluye seis paneles (Dirección, Economía, Servicios, Clientes, Proyección y Control), filtros, lectura móvil e impresión. La agenda futura se calcula desde la fecha actual del visitante.

## Datos y privacidad

La demo no está conectada a Odoo ni a la información de Grupo San Justo. Los nombres, importes, órdenes y comprobantes se generan en el navegador como muestra. No subir exportaciones, informes, copias de bases de datos ni información identificable a este repositorio público.

GitHub Pages es público. Para un tablero real de cliente se requiere autenticación individual y un alojamiento privado; el procedimiento de actualización local está documentado en [ACTUALIZACION_QUINCENAL.md](ACTUALIZACION_QUINCENAL.md).

## Publicación

GitHub Actions publica el contenido estático de la rama main en Pages. Al actualizar código de demostración, revisar que no se incorporaron archivos ni datos reales antes de hacer push.
